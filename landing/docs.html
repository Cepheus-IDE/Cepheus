Get started

  1. Install Cepheus on Windows 10 or 11. WebView2 is already part of Windows 11; on Windows 10 the installer adds it if it is missing.
  2. Open a project with Ctrl+O or File › Open Folder….
  3. Press Ctrl+L to open the agent panel and describe what you want to build or fix.

The agent starts on free NVIDIA models, so you don't need an API key for your first session. Install Git to use source control.

AI models

Choose a model from the picker at the bottom of the agent panel, or open Chat: Manage Language Models… from the Command Palette (Ctrl+Shift+P).

ProviderWhat you need
NVIDIA (free)Nothing. Optionally add your own nvapi-… key from build.nvidia.com for higher limits.
Anthropic ClaudeAn API key from console.anthropic.com
Google GeminiAn API key from aistudio.google.com
OpenAI-compatibleBase URL and key for OpenAI, OpenRouter, Groq and similar services. Add several under Providers.
Ollama, LM StudioA local server, e.g. http://localhost:11434/v1. No key, and no internet needed.

Auto picks a model for each request and falls back to the next one if a model returns a rate limit, a server error, a timeout or "not found". Models that are not available for your account are skipped from then on.

You can also run Claude Code or Codex as the agent if their command-line tools are installed. Pick them in the harness menu next to the model picker.

The agent

The agent can list, search and read files, create and edit them, run commands in your project, and keep a checklist of its plan. Choose how much it may do on its own:

ModeBehavior
AskAsks before every file edit and every command.
Auto-editEdits files on its own, asks before running commands.
TurboRuns everything without asking.

Plan mode

Turn on Plan in the chat footer to let the agent only read and research. It writes a plan; press Start implementation to continue in the same conversation.

Steer while it works

You can keep typing while the agent runs. Your message is queued and added before its next step, without stopping the work.

Verify with checks

Turn on Verify and the agent runs your project's checks when it finishes: typecheck, lint and test scripts from package.json, cargo check, go test or pytest. It fixes failures for up to three rounds.

Review and undo

Every file the agent changes appears in the Changes list. Open a diff, Keep the changes, or Revert all. Sessions are saved and come back after a restart. Run several tasks at once in the Agent Manager (Ctrl+Shift+M).

Customize the agent

Cepheus reads these files from the root of your project.

Instructions

AGENTS.md, CLAUDE.md, .github/copilot-instructions.md and every file in .cepheus/instructions/ are added to the agent's instructions. Limit a file to some paths with applyTo:

---
applyTo: "src/**/*.tsx, src/**/*.css"
---
Use function components and CSS modules. Never add new npm packages.

Skills

A skill is a folder with a SKILL.md and any scripts or templates it needs. The agent sees each skill's name and description, and loads the full text when it needs it.

.cepheus/skills/release-notes/SKILL.md
---
name: release-notes
description: Write release notes from the git log since the last tag
---
1. Run `git describe --tags --abbrev=0` to find the last tag.
2. Group commits into Features, Fixes and Other.

Custom agents

Files in .cepheus/agents/ define agents with their own instructions, an allowed tool list and an optional model. Pick one from the agent menu in the chat footer.

.cepheus/agents/reviewer.md
---
name: reviewer
description: Reviews changes without editing files
tools: [list_dir, find_files, read_file, search, run_command]
model: nvidia/nemotron-3-ultra-550b-a55b
---
Review the uncommitted changes. Report bugs by severity with file:line.

Hooks

Hooks in .cepheus/hooks.json run a command at a point in the agent's work. A preToolUse hook receives the tool call as JSON on stdin; if it exits with a non-zero code, the call is blocked and its error output is shown to the agent.

{
  "hooks": [
    { "event": "preToolUse", "matcher": "run_command", "command": "node scripts/check-command.js" },
    { "event": "stop", "command": "npm run lint" }
  ]
}

Events are preToolUse, postToolUse and stop. matcher is a regular expression on the tool name.

MCP servers

Connect the agent to databases, issue trackers, design tools and other services through the Model Context Protocol. Add global servers under Settings › MCP Servers, or per project in .cepheus/mcp.json:

{
  "servers": {
    "github": { "command": "npx", "args": ["-y", "@modelcontextprotocol/server-github"], "env": { "GITHUB_TOKEN": "…" } },
    "docs":   { "url": "https://example.com/mcp", "headers": { "Authorization": "Bearer …" } }
  }
}

Use command for local servers and url for remote ones. Their tools appear to the agent as mcp__server__tool and need your approval unless you are in Turbo mode.

Editing

JavaScript, TypeScript, JSON, CSS and HTML work out of the box. For other languages Cepheus starts a language server when one is installed, and offers a one-click install when it isn't.

Java, PHP, Ruby, Lua, C#jdtls, Intelephense, Solargraph, lua-language-server, csharp-ls

You get completion, hover, go to definition (F12), references (Shift+F12), rename (F2), quick fixes (Ctrl+.), refactorings (Ctrl+Shift+R), organize imports (Shift+Alt+O) and the Problems panel. Set a custom server command per language in Settings › Language Servers.

Snippets

Run Snippets: Configure User Snippets to edit snippets in the VS Code format, with tab stops ($1, ${1:name}) and variables such as $TM_FILENAME and $CURRENT_YEAR. Project snippets go in .cepheus/snippets/.

Terminal

Open it with Ctrl+`. Split it with Ctrl+\, pick PowerShell, pwsh, cmd, Git Bash or WSL, and Ctrl-click file paths in the output to open them.

Debugging

Open a JavaScript or TypeScript file and press F5. Click left of a line number (or press F9) for a breakpoint; right-click for a conditional breakpoint, hit count or logpoint. While paused you see variables, the call stack, watch expressions and values inline in the editor.

For more control, add .vscode/launch.json or .cepheus/launch.json with the gear in the Run and Debug view:

{
  "configurations": [
    { "type": "node", "request": "launch", "name": "Server", "program": "${workspaceFolder}/src/server.ts", "envFile": "${workspaceFolder}/.env" },
    { "type": "node", "request": "attach", "name": "Attach", "port": 9229 }
  ]
}

Python debugging uses debugpy (pip install debugpy).

Testing

The Testing view finds tests for Vitest, Jest, Node's built-in test runner, pytest, cargo test and go test. Run or debug all tests, a file or a single test from the tree or from the Run Test | Debug links above each test.

Failures show a red mark at the assertion with an expected/actual diff, and Fix with Agent starts a task with the failure. Turn on coverage to color covered and uncovered lines, or watch mode to rerun affected tests on save.

Git and GitHub

  • Changes: stage files or single hunks from the gutter, commit (with amend and sign-off), undo the last commit, stash, and Sync.
  • Merge conflicts: accept current, incoming or both inline, or open the three-way merge editor and press Complete Merge.
  • Commits: a graph of the branch with search; open any commit to see its changed files.
  • Branches: checkout, create, rename, delete, merge, rebase and tags. Click the branch in the status bar for a quick picker.
  • Timeline: the file's git history and its local history together.
  • GitHub: connect with a personal access token to clone, publish, review and merge pull requests, and turn issues into agent tasks.

Browser preview

When a dev server prints a local address, Cepheus offers to open it in a browser tab inside the editor. Run Browser: Open Preview of Current HTML File to serve a static page with live reload.

The tab has device sizes, DevTools and a console. Share with Agent sends the page's text, structure and console errors to the agent, and the agent can open, read and click through the page itself.

SSH and containers

Add a host in the Remote · SSH view (or import it from ~/.ssh/config) and open a folder on it. Files, terminals, git, search and the agent run on the server.

If the project has .devcontainer/devcontainer.json and Docker is installed, run Dev Containers: Reopen in Container. Terminals and agent commands then run inside the container.

Settings and profiles

Open settings with Ctrl+,, or edit them as JSON with Preferences: Open User Settings (JSON). A project can override editor and appearance settings in .cepheus/settings.json:

{ "tabSize": 4, "wordWrap": true, "theme": "builtin:paper" }
A project's settings file can only change how the editor looks and behaves. It can't change commands, language servers, AI providers or approval mode, so a cloned repository can't run anything on your machine through it.

Profiles bundle settings, shortcuts, extensions, snippets and layout, and can be exported to a .cepheus-profile file. Settings Sync keeps them in a private GitHub Gist; API keys and tokens are never synced.

Themes, icon themes and snippets install from Open VSX in the Extensions view (Ctrl+Shift+X). You can also import settings and themes from VS Code, Cursor, Windsurf or VSCodium.

For teams

Administrators can place a policy file that overrides user settings on every machine:

SystemPath
Windows%ProgramData%\Cepheus\policy.json
macOS/Library/Application Support/Cepheus/policy.json
Linux/etc/cepheus/policy.json
{
  "allowedProviders": ["nvidia", "anthropic"],
  "minimumApprovalMode": "auto-edit",
  "allowedMcpServers": ["github"],
  "extensionAllowlist": ["zhuangtongfa", "PKief.material-icon-theme"],
  "sharedInstructions": "Follow the team style guide in docs/STYLE.md.",
  "proxy": "http://proxy.internal:8080"
}

Locked settings show Managed by your organization in the app. Policy can also set allowed models and agent tools, preinstalled extensions, a private extension registry, extra trusted certificates and the update mode.

Build from source

Cepheus is open source under the MIT license. To build it you need Rust (stable, MSVC), the Visual Studio Build Tools with the C++ workload, and Node.js 18 or newer.

npm install
npm run app:dev     # run with hot reload
npm run app:build   # build the installer into src-tauri/target/release/bundle

The Rust core lives in src-tauri/src and the interface in src.
