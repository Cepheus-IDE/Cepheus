Apple apps without a Mac

Build for iPhone and macOS from any PC.

Cepheus writes a build workflow for your Xcode, SwiftUI, Flutter, React Native, Expo or Tauri project and runs it on GitHub's macOS machines. Watch the build live, then download the app.

  • Simulator builds and unsigned macOS apps need no Apple account
  • Signed .ipa and TestFlight upload with your own certificates as repository secrets
  • Preview Expo apps on your iPhone with a QR code

Installing on a real iPhone and publishing to TestFlight or the App Store require an Apple Developer Program membership. macOS runner minutes are free for public repositories; private repositories use your GitHub plan's minutes.

How it works

You describe it. You stay in control.

1

Describe

Type what you want in plain words. Turn on Plan mode to have the agent research and write a checklist before it touches anything.

2

Approve

Choose how much it may do alone: ask before every edit, edit freely but ask before commands, or run on its own.

3

Verify

It runs your tests, type checker or linter, reads the failures and tries again. Review every change as a diff, keep it or revert it in one click.

Built in Rust

Light where it counts.

The core of Cepheus is a native Rust program. It does not ship its own browser: the interface runs on the web view your system already has, WebView2 on Windows and WebKit on macOS and Linux.

10MBPrivate memory used by the Rust core
9MBSize of the app program
0Browser engines bundled

Measured on Windows 11 in November 2026: the Rust core (cepheus-ide.exe) used 10 MB of private memory, and the first 0.1.0 release program was 9.2 MB. The interface runs in WebView2 processes, whose memory grows with the files, terminals and previews you open, as in any browser-based editor.

FAQ

Questions, answered

Is Cepheus really free?

Yes. The app, the CLI and Cepheus Web are free and open source under the MIT license, and they include free access to NVIDIA Nemotron models. If you use paid providers such as Claude or Gemini, you pay them directly with your own key.

Do I need an API key to start?

No. Open a folder and ask the agent. The free tier allows 20 requests a minute and 400 a day. Add your own NVIDIA key (free at build.nvidia.com) for higher limits, or any other provider's key for other models.

Where does my code go?

Your files stay on your computer. When the agent uses a cloud model, the parts of your code it needs are sent to that provider only. With Ollama or LM Studio nothing leaves your machine. Cepheus itself collects no telemetry.

Which systems are supported?

Windows 10 and 11, macOS 11 or later (Apple silicon and Intel), and 64-bit Linux as an AppImage, .deb or .rpm package. You can also open folders on other machines over SSH or inside Dev Containers, use the CLI anywhere Node.js 18+ runs, or open Cepheus Web in Chrome or Edge.

Can I bring my VS Code themes and settings?

Yes. Import settings, color themes and snippets from VS Code, Cursor, Windsurf or VSCodium, or install themes from Open VSX.

Can I run AI models locally?

Yes. Point Cepheus at Ollama, LM Studio, llama.cpp, vLLM or any OpenAI-compatible server, on this computer or another machine on your network. The model runs in its own process, so Cepheus itself stays small. The model still needs memory of its own: roughly 5 GB for an 8B model and 40 GB for a 70B model when quantized. For very large models, run them on a strong server and connect Cepheus to it.

Can I build iPhone and Mac apps without a Mac?

Yes, through the cloud. Cepheus runs your build on GitHub's macOS machines and downloads the result. Simulator builds and unsigned macOS apps work without an Apple account; installing on a real iPhone or publishing to TestFlight or the App Store needs an Apple Developer Program membership.

Does it work with Docker?

Yes. The Docker view lists containers, compose projects, images and volumes, with logs, shells, stats and cleanup. You can also open a project inside a Dev Container and ask the agent to Dockerize a project with the built-in skill.

Is there a command-line version?

Yes. Install it with npm i -g cepheus-ide and run cepheus in any folder. It works with the free models, local models or your own keys, and cepheus web opens the full editor in your browser.

Which databases can I connect to?

PostgreSQL, MySQL, MariaDB, SQLite and SQL Server, directly or through an SSH tunnel. Passwords are stored in your system keychain, not in a settings file.

What happens if a free model is busy?

With Auto selected, Cepheus retries the request on the next available model, and remembers models that are not available for your account.
