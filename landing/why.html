Why Cepheus

A small app with a capable agent.

Cepheus is written in Rust, runs on the web engine your system already has, and is open source under the MIT license. Start coding with AI for free, read every line of the code, and keep your projects on your own machine.

Built in Rust

Light where it counts.

Files, search, git, terminals, language servers and the AI agent run in a native Rust core built on Tauri. Cepheus does not ship its own copy of Chromium. The interface runs in the system web view: Microsoft Edge WebView2 on Windows, WebKit on macOS and Linux.

Measured on Windows 11 in November 2026. The Rust core (cepheus-ide.exe) used 10 MB of private memory and a 48 MB working set. The program file of the first 0.1.0 release build was 9.2 MB; newer builds with more features may be somewhat larger. The interface runs in WebView2 processes whose memory grows with the files, terminals and previews you open, as in any browser-based editor.

Free to start

No account. No API key. No trial.

Cepheus comes with free access to NVIDIA Nemotron models served by NVIDIA NIM. Open a folder, type what you want, and the agent starts working.

When you outgrow the free tier, add your own key for Claude, Gemini, OpenAI, OpenRouter or Groq, or run models locally with Ollama or LM Studio and work fully offline.

  • Free models are selected by default on first launch
  • Auto mode picks a model per request and moves to the next one if a model is busy or unavailable
  • Your own keys always take priority over the free access
  • Local models through Ollama or LM Studio keep your code on your computer

Private and in control

The agent works for you, on your terms.

Your keys stay local

API keys are stored in your user folder and sent only to the provider you picked. Profiles and Settings Sync strip keys and tokens before anything leaves your machine.

You approve the risky parts

Ask before every edit and command, allow edits but ask before commands, or let it run on its own. Every change can be shown as a diff and reverted in one click.

Repos can't take over

A project's settings file may change how the editor looks, but never which commands run, which AI provider is used or how much the agent may do without asking.

Guardrails you can script

Hooks run your own checks before a tool call and can block it. Custom agents can be limited to a list of tools.

Ready for teams

A policy file can lock settings, limit providers, models and MCP servers, set the minimum approval mode and allow only approved extensions.

Works where your code lives

Open folders over SSH or inside a Dev Container. Files, terminals, git, search and the agent all run on that machine.
